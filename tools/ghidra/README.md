# tools/ghidra: Ghidra scripts and the census tags

Dev only, never ships. Workflow: `docs/workflows/ghidra.md`.

## What is here

| Path | What it is |
|---|---|
| `scripts/ghidra_http.py` | GET/POST client for the GhidraMCP plugin's HTTP API (`127.0.0.1:8089`, Ghidra GUI open) |
| `scripts/overlay_to_elf.py [--disc extracted] [--out-dir work/ghidra-import]` | Reads `G/LEVELn.WAD` for all 27 levels, wraps each level overlay (Ratchet executable format) as an ELF with the seven donor section names, writes `levelNN.elf` and `levelNN.overlay.bin`, and copies the boot ELF. `--overlay X.bin --out X.elf` converts one overlay. |
| `scripts/import_levels.py [NN ...]` | Imports `work/ghidra-import/SCUS_972.68` and `levelNN.elf` (00–26) into the open `ratchet2` project, waits for analysis, saves. No names (no Lombyte for this game): Version Tracking against R&C1's project instead (docs/plan/porting_from_rac1.md). |
| `scripts/export_decomp.py <program>` | Decompiled C of every function to `work/decomp/<program>/` (+ `index.tsv`) |
| `scripts/crossgame_diff.py --rc1 … --rc1-index … [--cite DIR] [--similar NAME...]` | R&C1 level01 vs Going Commando level01, function by function, with the relocation mask plus frame and scheduling normalisation; the R&C1 inputs come from R&C1's own folder; writes `work/crossgame/level01.tsv` |
| `names/census_systems.tsv` | System tags (system, has / partly / missing) of the shared functions the unported classes call; generated by `tools/census/tags.py`, read by `rc-trace class-census` (docs/plan/class_census.md) |

## Inputs and outputs

* **Inputs:** the open Ghidra project (`ratchet2`), the disc's files in `extracted/` (game data), the ELFs in
  `work/ghidra-import/`.
* **Outputs:** the ELFs in `work/ghidra-import/`, the decompiler export in `work/decomp/` (git-ignored: it is the
  game's code), the analysed programs in the Ghidra project.

Run from the repo root, e.g. `python3 tools/ghidra/scripts/export_decomp.py level00.elf`.
